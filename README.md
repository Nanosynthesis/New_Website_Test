# Chen Lab Website Test

Modern static website draft for the Nanosynthesis Consortium / Chen Lab at Westlake University.

## Structure

- `index.html` - homepage with hero, research areas, featured publications, team preview, news, and contact.
- `people.html` - principal investigator profile and current team grid.
- `publications.html` - searchable publication list rebuilt from the existing site through publication #210.
- `gallery.html` - recent group photos and activities.
- `assets/` - optimized images, CSS, and JavaScript data/rendering.

## Design References

The layout direction borrows from several current research-group websites:

- Nam Lab: full visual first screen and section rhythm across research, publications, people, and news.
- Fischer Nanolab: strong research highlights and current-team visibility.
- Mason Group: concise research-area framing.
- Taylor Lab: clear calls to research, papers, group, and joining/contact information.

No build step is required. The site can be served directly by GitHub Pages from the repository root.
